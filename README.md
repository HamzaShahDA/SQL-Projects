# SQL Portfolio Projects

This repository contains SQL projects focused on cleaning and preparing real-world datasets for analysis.

## Projects

### 1. Housing Data Cleaning

Cleaned a housing dataset using SQL Server. The project includes date standardization, missing-address handling, duplicate review, and other data-preparation tasks.

[View the Housing Data Cleaning project](./housing-data-cleaning)

### 2. Layoffs Data Cleaning

Cleaned a global layoffs dataset using staging tables, duplicate identification, data standardization, and structured SQL transformations.

[View the Layoffs Data Cleaning project](./layoffs-analysis)
