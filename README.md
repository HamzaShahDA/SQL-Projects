# SQL Data Cleaning Projects

This repository contains two SQL Server projects focused on cleaning and preparing datasets for analysis.

## Projects

### 1. Housing Data Cleaning

Creates a working copy of a housing dataset and cleans it by standardizing dates, filling missing property addresses, splitting address fields, standardizing category values, and removing duplicate records.

[View the Housing Data Cleaning project](./housing-data-cleaning)

### 2. Layoffs Data Cleaning

Creates a staging table for a global layoffs dataset and cleans it by handling blank values, standardizing text and dates, filling missing industries, and removing duplicate or unusable records.

[View the Layoffs Data Cleaning project](./layoffs-analysis)

## SQL Skills Used

- Staging and working tables
- `SELECT`, `UPDATE`, `DELETE`, and `ALTER TABLE`
- Self-joins
- Common table expressions
- `ROW_NUMBER()` window function
- String functions
- Date conversion
- Missing-value handling
- Duplicate removal
- Data standardization
